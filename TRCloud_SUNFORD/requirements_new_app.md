# ขอบเขตงานเฟสที่ 1

**ชื่อโครงการ:** พัฒนาแอปพลิเคชัน Android สำหรับรับเข้าสินค้า ชั่งน้ำหนัก และติดตามรายการด้วย SN เชื่อมต่อ TRCloud

## 1. วัตถุประสงค์

พัฒนาแอปพลิเคชัน Android สำหรับจุดรับเข้าสินค้า โดยผู้ใช้เข้าสู่ระบบตามสาขา ค้นหาสินค้าจาก TRCloud บันทึกการรับเข้าและน้ำหนัก สร้าง Record ID/SN และ Barcode พร้อมค้นหารายการย้อนหลังด้วย Barcode หรือ SN

เฟสนี้จะบันทึกได้ว่า SN แต่ละรายการถูกรับเข้าที่สาขาใด แต่ยังไม่มีการเปลี่ยนตำแหน่งหรือโอนย้าย SN ระหว่างสาขา

## 2. ระบบเข้าสู่ระบบและแยกสาขา

- เข้าสู่ระบบผ่านข้อมูลผู้ใช้งานที่เชื่อมต่อกับ TRCloud
- รับข้อมูล User Profile และ Permission
- กำหนดสาขาตามสิทธิ์ของผู้ใช้งาน
- ผู้ใช้ทั่วไปเข้าถึงข้อมูลเฉพาะสาขาของตนเอง
- ผู้ดูแลระบบสามารถเข้าถึงข้อมูลหลายสาขาตามสิทธิ์
- กรณีผู้ใช้มีสิทธิ์มากกว่าหนึ่งสาขา ระบบให้เลือกสาขาก่อนเริ่มงาน
- บันทึก User ID, Branch ID และวันเวลาของทุก Transaction
- รองรับการออกจากระบบและ Session หมดอายุ
- แจ้งเตือนเมื่อเข้าสู่ระบบไม่สำเร็จหรือไม่มีสิทธิ์ใช้งาน

## 3. ระบบค้นหาและเลือกสินค้า

- ค้นหาสินค้าด้วย SKU Code หรือชื่อสินค้า
- เรียกข้อมูลรายการสินค้าจาก TRCloud
- แสดงผลการค้นหา SKU
- เลือกสินค้าด้วย `item_id`
- เรียกดูรายละเอียดสินค้าจาก TRCloud
- แสดง Item ID, SKU, ชื่อสินค้า, หน่วยสินค้า และข้อมูลที่เกี่ยวข้อง
- รองรับกรณีไม่พบสินค้า
- รองรับกรณีข้อมูลสินค้าไม่ครบหรือ TRCloud ไม่ตอบสนอง

## 4. ระบบรับเข้าสินค้าและบันทึกการชั่ง

- เลือกสินค้าที่ต้องการรับเข้า
- ระบุ Lot ของสินค้า
- กรอกหรือรับค่าน้ำหนักสินค้า
- ตรวจสอบรูปแบบและความถูกต้องของน้ำหนัก
- รองรับการเชื่อมต่อเครื่องชั่งตามรุ่นและ Protocol ที่ตกลงจำนวน 1 รูปแบบ
- ระบุหมายเหตุของรายการรับเข้า
- บันทึกสาขาที่รับสินค้า
- บันทึกผู้ดำเนินการและวันเวลา
- ส่งคำขอ Create Inbound Weighing Record
- รับผลการบันทึก Record ID และ SN
- แสดงสถานะสำเร็จหรือไม่สำเร็จ
- ป้องกันการส่งรายการรับเข้าซ้ำ
- รองรับการส่งข้อมูลใหม่เมื่ออินเทอร์เน็ตหรือ API ขัดข้อง

ข้อมูลรายการรับเข้าประกอบด้วย:

- User ID
- Branch ID
- Item ID
- SKU
- Lot
- Weight
- Remark
- Record Date/Time
- Record ID
- SN
- Barcode
- Record Status

## 5. ระบบสร้าง SN และ Barcode

- สร้าง SN หรือรับ SN จากผลการบันทึกรายการ
- กำหนด Record ID/SN ให้ไม่ซ้ำกัน
- เชื่อมโยง SN กับ SKU, Lot, Weight และสาขาที่รับเข้า
- สร้าง EAN-13 สำหรับข้อมูล SKU และน้ำหนัก
- คำนวณ EAN-13 Check Digit
- สร้าง Code 128 หรือ QR Code สำหรับ Record ID/SN
- แสดงฉลากและ Barcode บนหน้าจอ
- เชื่อมต่อเครื่องพิมพ์ฉลากตามรุ่นที่ตกลงจำนวน 1 รูปแบบ
- สั่งพิมพ์ฉลาก Barcode/SN
- รองรับการพิมพ์ฉลากซ้ำ
- เก็บประวัติผู้ดำเนินการและเวลาที่พิมพ์

แนะนำให้ใช้ Code 128 หรือ QR Code เป็นรหัสหลักสำหรับติดตาม SN เนื่องจาก EAN-13 ที่ประกอบจาก SKU และน้ำหนักอาจซ้ำได้เมื่อสินค้าและน้ำหนักเท่ากัน

## 6. ระบบสแกนและค้นหา SN

- สแกน Barcode/SN ด้วยกล้องอุปกรณ์ Android
- รองรับ EAN-13, Code 128 หรือ QR Code ตามรูปแบบที่กำหนด
- รองรับการกรอก Record ID/SN ด้วยตนเอง
- ตรวจสอบความถูกต้องของ Barcode
- ค้นหารายการรับเข้าด้วย Barcode, Record ID หรือ SN
- แสดงรายละเอียดรายการรับเข้า
- แสดงสาขาที่รับสินค้า
- แสดง SKU, Lot, น้ำหนัก, วันเวลา และผู้บันทึก
- แสดงสถานะของรายการ
- แจ้งเตือนเมื่อไม่พบข้อมูลหรือ Barcode ไม่ถูกต้อง

## 7. การแยกข้อมูลตามสาขา

- ทุกรายการรับเข้าต้องผูกกับ Branch ID
- ผู้ใช้เห็นเฉพาะรายการของสาขาที่ได้รับสิทธิ์
- ผู้ดูแลระบบค้นหาและตรวจสอบข้อมูลทุกสาขาได้
- การค้นหาด้วย SN แสดงสาขาที่รับรายการนั้น
- ป้องกันผู้ใช้งานบันทึกข้อมูลเข้าสาขาที่ไม่มีสิทธิ์
- เก็บ Audit Log การเข้าถึงและการบันทึกข้อมูล

ในเฟสนี้ สาขาของ SN จะเป็น “สาขาที่รับเข้าครั้งแรก” และจะยังไม่มีการอัปเดตตำแหน่งจากการโอนย้าย

## 8. ระบบ SUNFORD Integration API

- พัฒนาระบบกลางเชื่อมต่อระหว่างแอป Android กับ TRCloud
- เชื่อมต่อ Login, User Profile และ Permission
- เชื่อมต่อข้อมูลสาขา
- เชื่อมต่อการค้นหา SKU
- เชื่อมต่อรายละเอียดสินค้าด้วย Item ID
- เชื่อมต่อการบันทึกรายการรับเข้า
- เชื่อมต่อการค้นหารายการด้วย Record ID/SN
- แปลงข้อมูลระหว่างรูปแบบของแอปและ TRCloud
- จัดเก็บ API Credential ไว้ในระบบ Backend
- ไม่จัดเก็บ TRCloud API Key ไว้ในแอปโดยตรง
- ป้องกันรายการซ้ำด้วย Idempotency Key
- กำหนด Timeout และ Retry
- จัดเก็บ Transaction Log และ Error Log
- รับส่งข้อมูลผ่าน HTTPS

## 9. แอปพลิเคชัน Android

- พัฒนาแอปพลิเคชันสำหรับ Android
- หน้าจอ Login และเลือกสาขา
- หน้าจอค้นหา SKU
- หน้าจอรายละเอียดสินค้า
- หน้าจอบันทึกรายการรับเข้าและน้ำหนัก
- หน้าจอแสดง Record ID/SN
- หน้าจอแสดงและพิมพ์ Barcode
- หน้าจอสแกน Barcode/SN
- หน้าจอแสดงรายละเอียดรายการรับเข้า
- รองรับสถานะ Loading, Empty, Error และ Retry
- จัดทำ App Icon และ Splash Screen
- กำหนดชื่อแอปตามที่ SUNFORD และลูกค้ายืนยัน
- สร้างไฟล์ APK และ Android App Bundle
- ทดสอบบนอุปกรณ์ Android จริง

## 10. Google Play Store

- เผยแพร่แอปผ่าน Google Play Developer Account ของ SUNFORD
- จัดเตรียมข้อมูลแอปและส่งตรวจจำนวน 1 ครั้ง
- ลูกค้าไม่ต้องมี Developer Account ในช่วงเริ่มต้น
- สามารถโอนแอปไปยัง Google Play Developer Account ของลูกค้าได้ภายหลัง
- รองรับการดำเนินการโอนย้ายแอปตามเงื่อนไขของ Google
- บัญชีปลายทางต้องเปิดใช้งานและผ่านเงื่อนไขของ Google
- ระยะเวลาตรวจสอบของ Google ไม่นับรวมในระยะเวลาพัฒนา

## 11. การทดสอบและ UAT

- ทดสอบ Login และ Permission ตามสาขา
- ทดสอบการค้นหา SKU
- ทดสอบการเลือกสินค้าด้วย Item ID
- ทดสอบการรับค่าน้ำหนัก
- ทดสอบการสร้างรายการรับเข้า
- ทดสอบการสร้าง Record ID/SN
- ทดสอบการสร้างและพิมพ์ Barcode
- ทดสอบการสแกนและค้นหา SN
- ทดสอบการแยกข้อมูลระหว่างสาขา
- ทดสอบการป้องกันรายการซ้ำ
- ทดสอบกรณีอินเทอร์เน็ตหรือ API ขัดข้อง
- ทดสอบร่วมกับเครื่องชั่งและเครื่องพิมพ์รุ่นที่ตกลง
- เปิดระบบให้ลูกค้าทดสอบ UAT
- แก้ไขข้อผิดพลาดตามขอบเขตที่ตกลง

## 12. การติดตั้งและส่งมอบ

- ติดตั้ง SUNFORD Integration API บนระบบ Production
- ตั้งค่า Environment และการเชื่อมต่อ TRCloud
- ส่งมอบ APK และ Android App Bundle
- ส่งมอบเอกสาร API Mapping
- ส่งมอบคู่มือการติดตั้งและใช้งาน
- ส่งมอบ Source Code ตามเงื่อนไขในใบเสนอราคา
- อบรมการใช้งานออนไลน์ 1 ครั้ง
- สนับสนุนการเปิดใช้งานจริง
- รับประกันแก้ไขข้อผิดพลาดตามขอบเขต 30 วันหลังส่งมอบ

## 13. ขอบเขตที่ไม่รวมในเฟสแรก

- ระบบเบิกสินค้าไปยังสาขา
- ระบบโอนย้ายสินค้าระหว่างสาขา
- ระบบยืนยันรับสินค้าที่สาขาปลายทาง
- สถานะสินค้าระหว่างขนส่ง
- ประวัติการเคลื่อนย้าย SN ระหว่างสาขา
- ระบบคืนสินค้าและย้ายกลับคลังกลาง
- ระบบบันทึกของเสีย
- การจัดหาหรือสมัครใช้บริการ TRCloud
- การจัดหาเครื่องชั่ง เครื่องพิมพ์ อุปกรณ์ Android และอุปกรณ์เครือข่าย

## 14. ระยะเวลาพัฒนา

| รูปแบบการพัฒนา | ระยะเวลา |
|---|---:|
| แบบปกติ | 30 วันทำการ |
| แบบเร่งด่วน | 15 วันทำการ |

ระยะเวลาพัฒนานับเฉพาะวันทำการตั้งแต่วันจันทร์ถึงวันศุกร์ ไม่รวมวันเสาร์ วันอาทิตย์ วันหยุดนักขัตฤกษ์ และวันหยุดตามประกาศของบริษัท

ระยะเวลาเริ่มนับเมื่อได้รับบัญชีทดสอบ TRCloud, API Credential, ข้อมูลสาขา, ข้อมูลสินค้าตัวอย่าง, เครื่องชั่ง และเครื่องพิมพ์สำหรับทดสอบครบถ้วนแล้ว
